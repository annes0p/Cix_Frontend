# CIXOIL S.A.C. — Frontend

Sistema web de gestión integral para CIXOIL S.A.C.

## Stack

- React + Vite
- Tailwind CSS v4
- React Router DOM
- Axios
- Lucide React
- Recharts

## Instalación

```bash
npm install
npm run dev
```
